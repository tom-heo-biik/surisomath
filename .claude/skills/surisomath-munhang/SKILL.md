# 수리소 수학학원 문항 퇴고 — 평가원 문형


## 환경
쓰임: 문제 글(지문·조건·보기·소문항·선지·정답)만 다룬다. 쪽과 단과 그림과 빌드는 양식 SKILL(surisomath-exam·surisomath-grind·surisomath-assess)의 것이다
정본: build/시험대비/20262학기중간/중3/이차함수·삼각비·원과직선의 problems.md와 problems.yaml(2026-09-23 첫 퇴고, 2026-09-26 둘째 퇴고와 독립 검토 둘). 세 파일 머리에 무엇을 왜 바꿨는지 문제마다 적혀 있다
검사기: templates/notation.py — 표기 규칙의 경계(기호가 식 밖에 홀로, 낱말 뒤에 = : < ⊥)를 잰다. 시험대비 build.py가 부르고, `python templates/notation.py <problems.yaml>`로 홀로 돌릴 수도 있다
검토자 브리핑: templates/review_brief.md — 독립 검토자(서브에이전트)에게 주는 글의 틀
평가원이란: 대학수학능력시험·모의평가 문항의 문형. 교육청 학력평가(고1 3월은 중학 내용)도 같은 결이다. 교과서·문제집 문형(오른쪽 그림에서, △ABC, ∠x, 이때)을 이 결로 옮기는 것이 이 스킬의 일이다


## 언제 · 어디에 · 되돌릴 수 있게
언제: 선생님이 "평가원 스타일로 퇴고"라 하면. 그전까지는 원문 그대로다. 선생님이 한 문제(이차함수 001)를 손보고 "나머지도 같은 결로"라 했으므로, 먼저 손본 문제의 결을 읽고 그 결을 따른다
어디에: problems.md 지문을 고치고 머리에 무엇을 어떻게 바꿨는지 적는다. yaml은 problems.md를 따른다(표기만 조판). problems.md는 선생님이 직접 고치는 파일이라 다시 읽은 뒤에만 쓴다
머리에 적는 것: 바꾼 문형(옛 글 → 새 글), 채운 조건, 뺀 딱지와 출처, 물음의 꼴을 바꾼 것(되돌리려면 이 줄), 검토가 권했지만 안 한 것과 그 까닭. 선생님이 되돌릴 수 있어야 한다
바꾸지 않는 것: 수식·수치·조건·답. 문제의 물음(이차함수 008 "x좌표를 모두 구하시오"를 "합을 구하시오"로 바꾸면 답이 바뀐다)
채우는 것: 엄밀함이 빠진 곳만. 이차함수 014 "(단, p ≠ 0)"(p = 0이면 직선 AB가 없다), 019 그림으로만 주던 x절편 2, 3, 4를 지문에. 원과직선 001 그림으로만 주던 네 길이, 013 그림으로만 보이던 "이웃한 두 원은 서로 접한다"(이 조건이 없으면 육각형의 둘레가 정해지지 않는다). 삼각비 026 "일정한 속력으로"(12분에 한 바퀴로 4분 뒤 자리를 재려면 필요). 채운 것은 머리에 적는다


## 문장의 짜임
흐름: 정의(…라 하자.) → 조건(…일 때,) → 물음. 정의와 조건을 한 문장에 섞지 않는다 — "…라 할 때, PR = 2이다. 구하시오" → "…라 하자. PR = 2일 때, 구하시오"(이차함수 020), "그래프 위의 점 P에 대하여 …같다. 제1사분면 위에 있을 때" → "그래프 위의 점 P가 제1사분면 위에 있다. …같을 때"(010), "…를 D라 하면 AB = AC + CD가 성립한다" → "…를 D라 하자. AB = AC + CD일 때"(삼각비 028). 물음에 쓰이는 점은 앞서 정의한다 — "이등분할 때, 직선 l과 선분 AC가 만나는 점 D의 좌표를" → "직선 l이 선분 AC와 만나는 점을 D라 하자. …이등분할 때, 점 D의 좌표를"(017). 상수는 도형 정의에 얹는다 — "∠B = 40°, AB = a, AC = b인 삼각형 ABC"(028), "BC = 10, CD = 6인 직사각형"(원과직선 008 "가로, 세로의 길이가 각각 10, 6인")
도형의 정의: "…에 대하여 사각형 ABCD는 …인 직사각형이다" → "…를 세 꼭짓점으로 하고 각 변이 x축 또는 y축에 평행한 직사각형 ABCD가 있다"(이차함수 004), "…를 꼭짓점으로 하는 평행사변형 ABCD가 있다"(006). "모든 변이" → "각 변이". "중심이 점 O로 일치하고" → "점 O를 중심으로 하는"(원과직선 004). "중심 O로부터의 거리가 6인 점 P" → "원의 내부에 OP = 6인 점 P"(005). "두 변 AB, BC 위의 두 점 D, E" → "변 AB 위의 점 D와 변 BC 위의 점 E"(원과직선 011, 삼각비 015). "각 변의 접점을 각각 D, E, F" → "세 변 AB, BC, CA와 접하는 점을 각각 D, E, F"(원과직선 012). "공통인 현 AB가 있다. 중심 사이의 거리가 7" → "서로 다른 두 점 A, B에서 만난다. O₁O₂ = 7"(019 — 평가원은 '공통인 현'이라 부르지 않는다). 넓이는 "곡선과 x축 및 두 직선 x = a, x = b로 둘러싸인"(이차함수 013). 두 원의 외접·내접에는 "서로"(원과직선 009 "점 A에서 서로 외접하는 두 원")
삼각형의 조건은 삼각형에, 점의 조건은 점에: "∠C = 90°인 직각삼각형 ABC의 변 AB 위의 점 D와 … 에 대하여 ∠AED = 90°"(삼각비 016). 삼각형의 변은 "변"이지 "선분"이 아니다(원과직선 020 "두 변 AB, BC의 연장선과 변 AC"). 점 O를 이름 없이 쓰지 않는다 — "원 O의 두 현 … 점 O에서"(원과직선 007)
"각각": 대응이 없는 나열("네 점을 각각 A, B, C, D", "두 점을 각각 A, C")에는 쓰지 않는다. 대응 목록이 있으면 "각각 + 목록"의 자리 — "각각 두 삼각형 ABC, ADC에 내접한다"(원과직선 014, 001·013·015와 같은 자리). 차례가 있으면 밝힌다 — "x좌표가 작은 것부터 차례로 P, Q, R, S"(이차함수 020). 동치인 조건은 평가원 말로 — "축의 오른쪽에 있는 점" → "x좌표가 큰 점"(009. 두 교점이 축의 양쪽에 있음을 확인하고 바꿨다)
조사: 종속절("~일 때")의 주어는 이/가 — "거리가 … 2배일 때"(이차함수 015). 주절의 진술은 화제에 는, 뒤따르는 새 사실에 가 — "세 현 AB, CD, EF는 서로 평행하고, 이웃한 두 현 사이의 거리가 같다."(원과직선 003, 선생님이 정한 문장. "…가 서로 평행하고 … 거리가 서로 같다"는 보고문처럼 무겁다. "평행하고 이웃한 두 현"으로 잘못 읽히지 않게 쉼표). 두 대상을 화제로 세운 뒤 그중 하나를 받을 때도 는 — "두 현 AB, AC에 대하여 현 AC는 원 C₂에 접하고"(004). "그림과 같이"로 여는 진술의 주어도 화제 — "두 원 O, O'은 각각 두 사각형 ABCD, CEFD에 내접한다"(001), "두 현 AB, CD는 점 E에서 서로 수직으로 만난다"(002. 선생님 지시 2026-09-26). 존재문 "…인 점 P가 있다", "…원 O가 있다"는 가 그대로. 한 문장에 같은 주어("두 원 O, O'이")가 두 번 오면 끊는다(014)
"서로"는 뜻으로 가른다: 세 현은 셋이 다 서로 평행하니 "서로 평행"이지만, 거리는 이웃한 두 현 사이(AB–CD, CD–EF)만 같고 AB–EF는 해당이 없으니 "서로 같다"라 하지 않는다(원과직선 003, 2026-09-26 선생님 지적. 되풀이를 피하려고 뺀 것이 아니다)
반복 구성(삼각비 014): A, B, C, D, …가 아니라 O, A₁, A₂, A₃, …(2026-09-26 선생님 지시). "…를 그려 직각삼각형 OA₁A₂를 만들고, … 이와 같은 과정을 계속하여 n번째로 만든 직각삼각형 OAₙAₙ₊₁에서 ∠AₙOAₙ₊₁ = θₙ°". 그림의 이름도 `$\mathrm{A}_1$` 꼴로 — 첨자 이름은 넓어서 단 너비를 넘기 쉽다
열린 물음: "둘레의 길이는 l cm 이상이다. l의 값을 구하시오"(삼각비 025)는 6√3보다 작은 l도 다 맞는다 → "둘레의 길이의 최솟값을 구하시오"(답은 6√3cm 그대로). "반직선 AE가 원과 만나는 점을 F"(023)는 A도 지나므로 "직선 AE가 원과 만나는 점 중 점 A가 아닌 점을 F"
실생활 문제: "그림은 … 측정한 결과이다"·"그림은 … 표지판이다" → 사람이나 사물을 주어로 "아리스타르코스는 … 구하기 위하여 그림과 같이 … 측정하였다"(삼각비 001), "그림과 같이 … 표지판이 있다"(009). "위해" → "위하여", "색종이" → "종이", "몇 도인지 구하시오" → "각의 크기를 구하시오", "제일" → "가장", "아래끝" → "아래 끝", "겹쳐지는" → "겹치는", "돈다고 한다" → "돈다". 접기는 "점 D가 점 B에 오도록 접었다. 점 C가 옮겨진 점을 P"(002)
단서: 제한이지 정의가 아니다. 단서의 접점(삼각비 007 "(단, … 접점은 각각 D, E이다.)")은 본문 정의로 — "변 AB와 접하는 점을 각각 D, E라 하고". 단서가 여럿이면 "(단, m > 0이고, O는 원점이다.)". 부등식만이면 마침표 없이 "(단, p ≠ 0)"
조건 상자 (가) (나): "이차함수 f(x)가 다음 조건을 만족시킨다." 뒤의 상자. 어느 문제를 상자로 만들지는 선생님이 정한다 — 조건이 둘이라고 무조건 상자로 만들지 않는다(2026-09-23). 알맹이 조건이 하나이고 나머지가 단서면 문장이 맞고, 상자는 4점급 무게로 읽힌다


## "그림과 같이"
여는 말: 그림 문제는 "그림과 같이 … 라 하자."로 연다. "다음 그림과 같이"·"오른쪽 그림과 같이"는 쓰지 않는다. "다음 그림은 … 나타낸 것으로"·"다음 그림에서 □ABCD는 직사각형이고"·"오른쪽 그림은 … 그린 것이다"도 "그림과 같이 … 가 있다"로 편다(원과직선 008·015·017). 그림 문제는 본문이 반드시 그림을 가리킨다 — 이차함수 005에 "그림과 같이"를 넣었다(정사각형 정의 쪽에. 물음 쪽에 두면 그림의 만나는 모양이 조건처럼 읽힌다)
"그림과 같이 …인" 절에는 그림에 보이는 것만 둔다(2026-09-26 선생님 지적, 원과직선 004). 그림에 없는 수치("반지름의 길이가 각각 8, 6인 두 원")를 거기 두면 그림이 거짓이 되고, 그리려면 반지름 같은 보조선이 생겨 문제가 달라진다. 그런 수치는 "…일 때" 절로 — "점 O를 중심으로 하는 두 원 C₁, C₂가 있다. … 두 원 C₁, C₂의 반지름의 길이가 각각 8, 6일 때". 문자(R₁, R₂)를 두었다가 바로 수를 주지는 않는다. 원과직선 004·006·007·017·019, 삼각비 017을 이렇게 내렸다. 그림에 점선 곡선으로 적힌 길이(원과직선 005의 6·10, 삼각비 002의 4cm·8cm)는 "…인" 절에 두어도 된다
원점: 그림에 원점 O가 있으면 단서 끝에 "(단, O는 원점이다.)"를 붙인다. 지문이 그림을 가리키지 않는 문제라도 그림에 O가 있으면 붙인다(2026-09-23 선생님 결정). 지문이 원점 O를 정의하면(이차함수 020 "원점 O와 점 A에서 만나고") 안 붙인다
그림이 정하는 것: 점의 이름이 어느 가지·어느 사분면인지는 "그림과 같이"가 정한다(이차함수 002·004). 수학적으로 다른 배치가 가능해도 평가원 관행 안이다. 그림의 점 이름은 지문이 다 부르거나, 안 부르는 이름은 뺀다(삼각비 030의 E). "…"로 이어지는 이름(014의 A₄~A₇)은 예외


## 물음
객관식은 "~은?", 서술형은 "~을 구하시오.". 보기 문제는 "옳은 것만을 보기에서 있는 대로 고른 것은?". "다음 중 항상 옳은 것은?"은 "두 양수 a, b에 대하여 항상 성립하는 것은?"처럼 대상을 밝힌다. "간단히 하면?" → "간단히 한 것은?". 소문항은 "다음 물음에 답하시오." 뒤 (1) (2) (3)
걷어내는 것: "이때,", "~일 때 … ~일 때"의 겹침, "~하였더니 … 되었다"(→ "~한 그래프가 x축과 만나는 두 점 사이의 거리가 … 의 2배일 때"), "구하시오" 앞의 "이때", 딱지([서술형]·[도전 문제]·[대표문제])와 출처([2016년 3월 교육청]), 책 번호, 그림의 화살표
낱말: 포물선 → 이차함수의 그래프. "x축에 서로 대칭인" → "x축에 대하여 대칭인". "접하고 있다" → "접한다". "m ≤ cos θ° ≤ M일 때" → "cos θ°의 최댓값을 M, 최솟값을 m이라 할 때". "삼등분하여, 점 B에 가까운 점" → "삼등분하는 두 점 중 점 B에 가까운 점"


## 표기 규칙 — 낱말과 기호
뜻이 가른다: 기호 `$\overline{\mathrm{AD}}$`는 "선분 AD의 길이"라는 수이고 낱말 "선분 AC"는 도형이다. 길이·크기라는 수를 식 안에서 쓰면 기호(AD̄ = 6, ∠B = 90°, ∠CDH = θ°, AP̄² + BP̄², BD̄/DC̄), 도형 그 자체를 가리키면 낱말(선분 AC, 각 C, 변 BC, 호 AB, 현 AB, 삼각형 ABC, 사각형 ABCD). 그래서 삼각비 012처럼 한 문제 안에 "$\overline{\mathrm{AD}}=6$"과 "선분 AC는 각 C의 이등분선이다"가 같이 서는 것이 맞다(2026-09-23 선생님 결정, 2026-09-26 "어떤 규칙이냐"고 물은 뒤 유지로 확정. 문제집처럼 모두 기호, 또는 모두 낱말도 보였지만 평가원 방식을 골랐다)
관계 기호: 수직 `$\overline{\mathrm{OC}}\perp\overline{\mathrm{AB}}$`는 수가 아니라 관계인데도 기호다 — 실제 경계는 "관계 기호(=, :, <, ⊥)로 잇는 식이면 기호, 서술이면 낱말"이다(원과직선 004·016은 기호, 002 "점 E에서 서로 수직으로 만난다"는 서술. 중1 교과서가 수직을 AB̄ ⊥ CD̄로 정의한다)
검사기: templates/notation.py가 경계를 지킨다 — 기호가 식 밖에 홀로 있으면("$\overline{\mathrm{AC}}$는 …", "$\angle\mathrm{C}$의 이등분선") 도형을 기호로 쓴 것, 낱말 뒤에 = : < ⊥가 오면("선분 $\mathrm{AB}$ = 6") 길이를 낱말로 쓴 것이라 `!`로 경고한다. 시험대비 build.py가 문제마다 부른다. 일흔 문제에서 오탐 0
