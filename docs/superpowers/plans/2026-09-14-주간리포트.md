### Task 2: 괘선 좌표 검사

- [ ] **Step 1: pdfplumber로 가로선 y를 모두 뽑는다**

```python
import pdfplumber
with pdfplumber.open("build/주간리포트/수리소_주간리포트.pdf") as pdf:
    p = pdf.pages[0]
    ys = sorted({round(l["top"], 2) for l in p.lines + p.rects if abs(l["top"] - l["bottom"]) < 1})
    print([round((y - 72) / 22, 2) for y in ys])   # 본문 위 기준 칸 수
```
Expected: 표 선이 3, 4.5, 6, 7.5, … 21 (행마다 아래선은 정수, 가운데선은 x.5), 말씀 괘선이 24.5, 26, 27.5, 29.
