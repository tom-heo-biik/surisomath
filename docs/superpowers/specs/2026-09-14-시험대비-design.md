# 수리소 시험대비 학습지 설계

2026. 9. 14.

## 무엇인가

학교 시험을 앞두고 푸는 실전 모의 학습지. 선생님이 시험 범위 단원마다 문제를 짓고, 학생은
학교 시험지처럼 두 단으로 짜인 종이에 손으로 푼다. 선생님 쪽에는 정답과 풀이가 붙는다.

- 시리즈 이름: 시험대비
- 독자: 학생(학생 쪽), 선생님(선생님 쪽)
- 매체: A4 여러 장. 종이에 펜으로 푼다
- 산출물: 단원 하나에 PDF 하나. 학생 쪽 뒤에 선생님 쪽이 같은 차례로 붙는다
- 양식 기반: surisomath-a4(A4 595×842pt, 22pt 베이스라인 그리드, KoPubWorld 바탕체).
  그림 도우미와 본문 수식 조판은 surisomath-grind 것을 빌려 쓴다
- 첫 단원: build/시험대비/20262학기중간/중3/삼각비/problems.md. 문제 열 개, 객관식 둘,
  그림 아홉

연마(硏磨)와 다른 점은 셋이다. 한 쪽에 문제가 둘이고, 풀 자리가 두 단이 아니라 문제 아래
빈 종이이며, 낱말로 쓴 도형 표기를 교과서 기호로 조판한다.

## 쪽의 짜임

두 단, 단마다 문제 하나. 학생 쪽은 문제 열 개에 다섯 쪽. 본문 영역 475×682pt(22pt × 31칸)를
위에서부터 이렇게 쓴다. 기준은 본문 영역 위 끝.

| 위치(pt) | 내용 |
|---|---|
| 0~11 | 빈 반 칸 |
| 11~33 | 머리줄. 왼쪽에 "시험대비 · 2026학년도 2학기 중간고사 · 중3 · 삼각비"(typo-0, neutral-1000). 첫 쪽만 오른쪽 끝에 "이름"과 펜으로 쓸 빈 자리 |
| 33~44 | 빈 반 칸 |
| 44~66 | 문제 번호. typo-4(20pt/700), 단마다 왼끝. 제목 위상(22k) |
| 66~77 | 번호 아래 반 칸 |
| 77~ | 지문 → 그림 → 선지. 블록 사이 한 칸(22pt). 본문 위상(11 + 22k) |
| 그 아래~682 | 풀 자리. 빈 종이. 소제목·심볼·가로선 없음 |

- 반 칸을 두 번 비우는 까닭은 연마와 같다. 머리줄 글자는 본문 위상, 번호는 제목 위상에 있어야
  한다. 11 + 22 + 11 + 22 + 11 = 77
- 문제 글부터 바닥까지 27.5칸. 풀 자리는 27.5칸에서 문제 블록(지문·그림·선지와 그 사이·아래
  한 칸씩)의 칸 수를 뺀 것이라 늘 .5로 끝난다. 짧은 문제(010)에서 18.5칸, 가장 긴 001에서
  10.5칸(231pt), 005에서 11.5칸
- 쪽마다 짜임이 같다. 제목 줄은 따로 두지 않는다. 두면 첫 쪽만 단이 짧아지고 20pt 제목 아래
  20pt 번호가 붙어 위계가 부딪힌다. 머리줄에 시험·학년·단원이 다 있다
- 쪽번호: a4 그대로(- n -). 선생님 쪽까지 이어 센다

### 이름 칸

첫 쪽 머리줄 오른쪽 끝. "이름"(typo-0) 뒤에 너비 90pt의 inline-block을 두고 아래에 0.4pt 선을
긋는다. &nbsp;로 비우면 render.py의 어절 처리가 접으므로 너비를 가진 상자로 비운다. 선 두께는
상자 안에서 뺀다(주간 리포트와 같다). 학생은 선 위에 이름을 쓴다.

## 단

- 왼 단 x = 0~237pt, 오른 단 237~475pt. 가운데 세로선 하나(neutral-1000, 0.4pt)가 x = 237pt
  (쪽 기준 297pt)에 번호 줄 위(44pt)부터 바닥(682pt)까지 선다. 정수 좌표에 두는 까닭은 연마와
  같다. 반반(237.5)이면 화면에서 회색으로 보인다
- 글은 선에서 8pt 안쪽. 왼 단 글 너비 229pt(0~229), 오른 단 230pt(245~475). 바깥쪽 선은
  없으므로 바깥 여백은 없다
- 세로선은 하나뿐이다. 학교 시험지 꼴이다. 연마의 세 줄 상자는 두 번 푸는 자리라 여기 안 맞는다
- 가로선: 없음
- 한 쪽은 `<section class="exam">` 하나. 문제가 단을 넘치면 빌드가 멈추므로 섹션 중간에서
  쪽이 끊기는 일은 없다

## 문제 하나의 짜임

### 번호

001, 002, … 세 자리. problems.md에 적힌 차례대로. 순서는 바꾸지 않는다. 003과 006이
숫자만 다른 같은 문제인 것도 그대로 둔다 — 선생님이 지은 대로다.

### 지문

typo-1(12pt/300), 한 문단, 어절 줄 바꿈은 render.py가 한다. 문장은 problems.md 그대로다.
끝맺음·도입·조사를 바꾸지 않는다. 바꾸는 것은 표기뿐이다.

### 표기 규칙

낱말로 쓴 도형 표기를 교과서 기호로 조판한다. 연마의 규칙(`!=` → `\neq`, `b/x` → `\dfrac{b}{x}`)
위에 이것이 얹힌다.

| 원문 | 조판 |
|---|---|
| 선분 AB | `$\overline{\mathrm{AB}}$` |
| 각 A, 각 BAC | `$\angle\mathrm{A}$`, `$\angle\mathrm{BAC}$` |
| 삼각형 ABC | `$\triangle\mathrm{ABC}$` |
| 사각형 ABCD | `$\square\mathrm{ABCD}$` |
| 루트 (…)^2, 2루트3 | `$\sqrt{(\cdots)^2}$`, `$2\sqrt{3}$` |
| sinx, tan 52°, 35° | `$\sin x$`, `$\tan 52^\circ$`, `$35^\circ$` |
| 각 BAC = 60°, tan63°=1.96 | `$\angle\mathrm{BAC}=60^\circ$`, `$\tan 63^\circ=1.96$` |
| 80 / (tan 52° + tan 35°) | `$\dfrac{80}{\tan 52^\circ+\tan 35^\circ}$` |

낱말로 남기는 것. 교과서에서도 낱말로 쓴다.

- 직각삼각형 ABC, 정사각형 ABCD, 직사각형 ABCD → 낱말 그대로, 이름만 정체(`$\mathrm{ABCD}$`)
- 점 A, 지점 A, 직선 $l$, 중점 M → 낱말 그대로. 점 이름은 정체, 직선 이름 $l$은 이탤릭
- 80m, 4cm, 124m, 30% 같은 치수 → 글자 그대로(a4의 단위 붙여쓰기). 수식 안의 값에 단위가
  붙으면 `$\overline{\mathrm{AB}}=8$cm`처럼 수식 뒤에 글자로 붙인다

각도는 낱말 사이에 홀로 있어도 전부 수식 서체다. 35°가 글자, 60°가 수식이면 한 쪽 안에서
숫자 모양이 두 가지가 된다. 변수는 이탤릭(`$x$`), 점 이름은 정체 — 연마 규칙이다.

### 그림

- 자리: 지문 아래, 단 가운데. a4의 `.figure` 블록
- 높이: units × 22pt. yaml에 units를 적지 않는다. SVG 높이가 칸 수를 정하고 빌드는 22의
  배수인지만 본다(허용 0.05pt). 연마는 yaml의 units와 그림을 맞춰 보지만, 그림이 아홉 개면
  두 곳에 적는 것이 짐이다
- 너비: 229pt 안. 넘으면 빌드가 멈추고 y 범위를 얼마로 키우라고 알려 준다. 연마에는 없던
  검사다. 단이 좁아 필요하다. 배율·잉크 여백·선 두께·글자 크기는 연마 규격 그대로
- 삽화는 그리지 않는다. 산·기구·성산일출봉은 지면 선 위의 삼각형이다. 교과서 삽화의 자리에
  도형만 둔다

### 선지

객관식은 지문(과 그림) 아래에 `<ol class="n7">`(① ② ③ ④ ⑤, 마커 칸 22pt)로 둔다. 수능·모의고사
관례대로 너비에 따라 열 수를 정한다. 빌드가 선지마다 너비를 재서 고른다(수식은 SVG 너비,
글자는 KoPub 서체 폭).

| 열 | 배치 | 조건 |
|---|---|---|
| 5열 | ① ② ③ ④ ⑤ 한 줄 | 다섯 모두 마커 칸 22pt + 글 너비 ≤ 단 글 너비 ÷ 5(45.8pt) |
| 3열 | ① ② ③ / ④ ⑤ 두 줄. ④는 ① 아래 | 다섯 모두 ≤ 단 글 너비 ÷ 3(76.3pt) |
| 1열 | 한 줄에 하나, 다섯 줄 | 나머지 |

칸 너비가 같아 ④가 ① 아래 온다. 001은 분수라 1열 다섯 줄, 010은 ④ ⑤가 76pt를 넘어 1열이다.
선지 한 줄은 한 칸(22pt). 선지 블록 아래 한 칸 비우고 풀 자리가 시작한다.

### 넣지 않는 것

답 칸, 배점, [서술형] 표시. 문제 글에 없는 것은 넣지 않는다.

## 선생님 쪽

- 학생 쪽 다섯 장 뒤에 같은 차례로 다섯 장(6~10쪽). 양식은 학생 쪽과 똑같다. 첫 쪽의 이름 칸은
  선생님 쪽에 없다
- 각 단의 풀 자리 첫 줄에 "정답: ④"(typo-0, neutral-500, 왼끝). 그 다음 줄부터 풀이. 연마는
  정답을 머리줄 오른쪽 끝에 두지만 여기선 한 쪽에 문제가 둘이라 단 안으로 내린다. 풀 자리
  첫 줄은 본문 위상이라 10pt 글자가 머리줄과 같은 그리드 잔여값에 앉는다
- 정답 표기: 객관식은 번호만("정답: ④"). 서술형은 단위까지 붙여 쓴다(182.35m, 2% 감소).
  정답 줄은 한 줄, 단 글 너비 안. 넘으면 빌드가 경고한다
- 풀이: yaml의 `solution: |` 블록. 줄마다 한 칸, 빈 줄은 한 칸을 비운다. typo-1, 수식은 `$…$`.
  한 줄이 단 너비(한글 19자쯤)를 안 넘게 짧게 끊어 쓴다. 단 바닥을 넘으면 빌드가 경고한다
- 풀이 문체: 연마 규칙 그대로. 서술형 모범 답안. 전개만 쓰고 대입한 식·계산은 일부러 생략.
  "~이므로 ~이다." 마지막 줄 "따라서 …이다." 그림은 "주어진 그림에서". 객관식은 마지막 줄에
  식을 적고 정답 줄이 번호를 맡는다
- 정답·풀이 초안은 Claude가 쓰고 선생님이 다듬는다. 연마와 같다

## 그림

### 도우미에 보태는 것

삼각비 그림에 연마에 없던 표시가 필요하다. grind_figure.py에 보태서 연마에서도 쓴다.

| 도우미 | 하는 일 | 규격 |
|---|---|---|
| `g.angle(ax, v, p, q, text, r)` | 꼭짓점 v에서 p·q 방향 사이에 호를 긋고 글을 이등분선 위 호 바깥에 앉힌다 | 호 0.4pt, 반지름 r pt(기본 12), 글 10pt. 각도 글은 `$35^\circ$`로 수식 서체 |
| `g.tick(ax, p, q, n)` | 선분 pq 한가운데에 짧은 획 n개. 같은 길이 표시 | 0.4pt, 길이 5pt, 획 사이 2pt |
| `g.poly(ax, pts, dashed=True)` | 점선 도형 | 0.7pt, 대시 2pt 간격 2pt(matplotlib이 선 두께를 곱하므로 나눠서 준다) |
| `g.axis(ax, p, q, text)` | 회전축 | 일점쇄선 0.4pt. 교과서의 회전축 표기 |

직각 표시(`g.right_angle`·`g.foot`), 길이 표시(`g.dim`), 색칠(`g.shade`)은 연마 것을 쓴다.

## 파일

### 스킬

```
.claude/skills/surisomath-exam/
├─ SKILL.md
└─ templates/
   ├─ exam.css      base.css 위에 얹는 시험대비 스타일(두 단·세로선·머리줄·이름 칸·선지 열·정답 줄)
   ├─ build.py      problems.yaml → 그림 → 수식 → HTML → PDF → 검사
   └─ sample/       견본. 문제 둘(객관식 하나·서술형 하나, 그림 있음) → 학생 한 쪽 + 선생님 한 쪽
```

- base.css는 `../../surisomath-a4/templates/base.css`를 상대 경로로 링크한다. 복사하지 않는다
- build.py는 연마의 build.py를 모듈로 읽어(`__main__` 가드가 있다) 수식 조판(`rich`·`inline_style`),
  SVG 높이 읽기, 수식 상자 겹침 검사를 그대로 쓴다. figures.py가 `import grind_figure as g`를
  찾도록 연마 templates 폴더를 경로에 넣어 준다. 같은 코드를 복사하지 않는다
- 심볼은 없다. 소제목이 없어서다

### 단원 폴더

```
build/시험대비/<시험>/<학년>/<단원>/
├─ problems.md      선생님 원문. 손대지 않는다
├─ problems.yaml    빌드 입력. 조판한 지문·선지·정답·풀이·그림 이름
├─ figures.py       그 단원 그림만. 그림이 없으면 두지 않는다
├─ figures/         빌드가 만든 SVG(그림 p*.svg, 수식 m*·c*·a*·s*.svg)
├─ 수리소_시험대비_2026_2학기중간_중3_삼각비.html
└─ 수리소_시험대비_2026_2학기중간_중3_삼각비.pdf
```

- 시험 폴더 이름은 `YYYY` + `N학기` + `중간|기말`(20262학기중간). 빌드가 정규식
  `^(\d{4})(\d)학기(중간|기말)$`로 읽어 "2026학년도 2학기 중간고사"를 만든다. 학년·단원 폴더
  이름은 그대로 쓴다
- 머리줄과 `<title>`: "시험대비 · 2026학년도 2학기 중간고사 · 중3 · 삼각비"
- 파일 이름: 수리소_시험대비_<YYYY>_<N학기><중간|기말>_<학년>_<단원>. 연도 뒤에 밑줄을 하나
  넣어 20262학기중간을 읽기 쉽게 한다
- PDF의 만든 날짜는 학기 첫날(1학기 3. 1., 2학기 9. 1.)로 고정한다(SOURCE_DATE_EPOCH). 같은
  입력이면 PDF도 바이트 단위로 같다

### problems.md

선생님이 쓰는 원문. 이번 단원이 정한 꼴이다.

```
## 001

### 지문
다음 그림과 같이 80m 떨어진 두 지점 A, B에서 …

### 그림
각 CAH가 35°, 각 CBH가 52°, 각 CHA가 직각인 그림

### 선지
1. 80 / (tan 52° + tan 35°)
2. …
```

빌드는 이 파일을 읽지 않는다. 지문에 수식이 섞여 자동으로 조판할 수 없고, 조판하려면
원문을 고쳐야 하기 때문이다. 원문은 그대로 두고 옆의 yaml에 조판본을 둔다. yaml 지문이
원문과 표기 말고 다른 데가 없는지는 Claude가 읽어서 맞춘다.

### problems.yaml

```yaml
# exam · grade · unit · file은 폴더 이름에서 만든다. 바꿀 때만 적는다
problems:
  - text: 다음 그림과 같이 80m 떨어진 두 지점 $\mathrm{A}$, $\mathrm{B}$에서 …
    figure: p1.svg            # figures/ 안의 그림. units는 없다 — SVG 높이가 정한다
    alt: 각 CAH가 35°, …       # problems.md의 그림 설명 그대로. PDF에는 안 찍힌다
    choices:                  # 있으면 객관식. 다섯 개
      - $\dfrac{80}{\tan 52^\circ+\tan 35^\circ}$
      - …
    answer: ④
    solution: |
      주어진 그림에서 …
      따라서 …이다.
  - text: …
    answer: 182.35m
    solution: |
      …
```

- `"no": "004"`로 번호를 직접 줄 수 있다. 키까지 따옴표 — 연마와 같다
- text에 ": "가 들어가면 따옴표로 감싼다
- 선생님 쪽은 학생 쪽과 같은 짝으로 짠다. solution이 없는 문제는 그 단의 풀 자리가 비고 정답도
  안 찍힌다. 문제 전부에 solution이 없으면 선생님 쪽을 붙이지 않는다. 연마는 한 문제가 한 쪽이라
  그 문제만 빼지만, 여기선 짝이 밀리지 않게 자리를 지킨다

## 빌드와 검사

```
python .claude/skills/surisomath-exam/templates/build.py build/시험대비/20262학기중간/중3/삼각비/problems.yaml
```

하는 일: figures.py 실행 → 수식 SVG → HTML → render.py로 PDF → 검사. 경고가 하나라도
있으면 종료 코드 1. PDF는 그래도 나온다. `!` 줄이 무엇을 어떻게 고치라고 말한다.

| 검사 | 기준 | 어긋나면 |
|---|---|---|
| 그리드 | a4 render.py --check "이상 없음" | 경고 |
| 단 넘침 | 문제 블록(번호~선지)이 682pt 안에 든다 | 멈춤. 어느 문제가 몇 칸 넘는지 |
| 풀 자리 | 단마다 남은 칸 수를 알려 준다. 8칸 아래면 | 경고 |
| 그림 높이 | 22의 배수(허용 0.05pt) | 멈춤 |
| 그림 너비 | ≤ 229pt | 멈춤. y 범위를 얼마로 키우라고 |
| 수식 상자 | 잇단 줄의 수식 상자가 안 겹친다(연마 검사) | 경고 |
| 정답 줄 | 한 줄, ≤ 단 글 너비 | 경고 |
| 풀이 | 단 바닥을 안 넘는다 | 경고 |
| 선지 | 다섯 개 | 멈춤 |

## 확인 기준

1. 빌드 경고 0. 그리드 검사 "이상 없음"
2. PDF 10쪽. 학생 쪽 1~5, 선생님 쪽 6~10, 쪽번호 이어짐
3. 눈으로 본다. 그림이 문제와 맞는지, 각도 글이 선에 안 걸리는지, 선지 열이 관례대로인지,
   가운데 선이 검게 찍히는지
4. 인쇄해서 풀어 본다. 가장 좁은 풀 자리(001, 231pt)가 손으로 풀기에 충분한지
5. 선생님이 정답·풀이를 검토한다. 문제를 지은 사람이 답을 안다

## 정하지 않은 것

- 배점·답 칸·[서술형] 표시. 문제 글에 없으니 안 넣는다. 필요해지면 그때 설계한다
- 시험 범위 여러 단원을 한 파일로 합치는 것(범위 전체 모의). 단원 하나 = 학습지 하나로 시작한다
- 문제 순서. md 차례 그대로다. 유형을 섞을지는 선생님이 md에서 정한다
- 연마의 표기 규칙을 시험대비 것(낱말 → 기호)으로 바꿀지. 따로 정한다
- 이름 칸의 크기·모양. 첫 인쇄 뒤에 다시 본다
